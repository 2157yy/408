# 408 纸上复习室

一个面向计算机考研 408 的逐题复习网页。每次专注一张题卡：先独立作答，再查看逐步解析、教材知识点图解，或进入对应的动画演示。

## 功能

- **真题卡片：** 收录 200 道题，支持按科目、年份、题型筛选，也可以搜索题号和题目内容。
- **完整题目：** 展示题干原文、段落与小问格式。选择题提供可点击选项和答案核对；开放题保留原题形式。
- **独立题图：** 从原题提取 103 张图表，按题目顺序展示，不使用整页截图。图片存放在本地并按需加载。
- **逐步解析：** 将解题思路分成小步，附易错提醒、教材定位和通俗讲解；知识点图片可点击放大。
- **动画实验室：** 提供 18 个交互式演示，覆盖图算法、排序、操作系统、组成原理和计算机网络等知识点。
- **移动端适配：** 题卡、筛选器、图解和动画控制可在手机屏幕上使用。

## 本地运行

需要安装 Node.js 和 npm。

```sh
npm install
npm run dev
```

生产构建与预览：

```sh
npm run build
npm run preview
```

网页通过 Vite 服务运行，不能直接双击 `index.html` 打开。已掌握题目的标记保存在当前浏览器的本地存储中。

## 项目结构

```text
src/
  App.tsx              题卡、筛选、答题与解析界面
  AnimationLab.tsx     分步骤交互动画
  knowledge.ts         教材知识点图与白话说明
  questionMedia.ts     题目与动画演示的关联
public/
  questions.json       题目元数据与逐步解析
  question-details.json 题干原文、选项、排版结构和配图索引
  question-diagrams/   从真题原页提取的本地题图
  assets/              教材知识点示意图
```

四本教材 PDF 可放在仓库根目录的 `book/` 文件夹中供本地整理使用；该目录已加入 `.gitignore`，不随项目提交。网页使用的知识点示意图存放在 `public/assets/`。

## 真题来源与整理说明

真题题干与配图来源于 [BOK408 历年真题档案室](https://zhenti.beokayy.club)。题目卡片保留原题段落和小问顺序；含图题使用独立本地配图，避免加载整张网页截图。2026 年带 † 的题目为公开回忆整理版。
